# Reel Cutter — بلاجن بريمير لقص الريلز من الشيت

تلزق خلايا الشيت اللي بيبعتها مسئول المحتوى، والبلاجن يعمل Sequence لكل ريل: المقاطع ورا بعض والصوت معاها، على التمبلت بتاعك (لوجو/بوردر/Black Matte)، وعلى أول كل مقطع marker باسم الجملة.

## التسطيب (على أي جهاز ويندوز)
محتاج: **Premiere Pro 26.3 أو أحدث** و**Creative Cloud** متسطب.

1. انقل فولدر `ReelCutter-1.0.0` للجهاز (فلاشة، Google Drive، OneDrive… أي طريقة).
2. افتح الفولدر ودبل كليك على **`install-windows.bat`**. هيظهر `Installation Successful`.
   - أو: دبل كليك على ملف **`ReelCutter-1.0.0.ccx`**، فـ Creative Cloud هيسطّبه. لو قالك إن البلاجن مش متوثّق، وافق، لأنه بلاجن شخصي مش من متجر Adobe.
3. افتح بريمير ← **Window ← UXP Plugins ← Reel Cutter**.
4. اسحب البانل وحطه جنب Properties أو Effect Controls، وبريمير هيفتكر مكانه.

> **مش محتاج UXP Developer Tools** ولا Developer Mode على الأجهزة التانية. دول كانوا للتطوير بس.

**على الماك:** دبل كليك على ملف الـ `.ccx` (Creative Cloud بيسطّبه). الكود نفسه شغال على الماك، بس لسه ما اتجربش عليه.

## الاستخدام
1. **الزق الشيت:** حدّد خلايا الريلز في Google Sheets بكل الأعمدة (الثواني، الجمل، الشركة، الفيديو) واعمل Ctrl+C، وبعدين Ctrl+V في البانل ← **حلّل**.
2. **راجع:** كل ريل في كارت، والأخطاء بالأحمر (زي `08:148`). تقدر تعدّل الوقت مكانه، أو تختار الفيديو والتمبلت، أو تعلّم "تخطّي".
3. **اعمل:** الريلز بتتعمل في Bin اسمه `REELS`. ولو حاجة طلعت غلط: **امسح ريلز آخر تشغيل**.

## التمبلتس
- اعمل Sequence اسمها بيبدأ بـ **`TPL_`** (مثلًا `TPL_Acme`) بمقاس الريل، وحط اللوجو والبوردر والـ Black Matte على **V2 وفوق**. **سيب V1 وA1 فاضيين.**
- في جدول المراجعة اختار التمبلت للريل. لو الريل مكتوب فيه اسم شركة، البلاجن **بيفتكر** التمبلت للشركة دي المرة الجاية.
- اللايرز بتتمد أو تتقصّر لحد آخر الريل بالظبط.

## الإعدادات (زرار ⚙)
- **ثواني زيادة قبل/بعد** كل مقطع.
- **اسم الـ SEQ:** `{company}` و`{video}` و`{nn}` (01) و`{n}` (1).
- **Markers:** تشغيل وإيقاف.
- **التمبلت الافتراضي** وقايمة الشركات المتسجلة.

الإعدادات **بتفضل زي ما هي لما تسطّب نسخة أحدث**. بتتمسح بس لو عملت Uninstall للبلاجن.

## الفونت المدمج (Palestine + Impact)
- على جهازك: `tools\merge-font\gui.pyw` (التفاصيل في [README الأداة](tools/merge-font/README.md)).
- على أجهزتك التانية: انسخ ملف الخط من `tools\merge-font\output\`، واعمل عليه كليك يمين ← **Install**، وبعدين اقفل بريمير وافتحه.
- ⚠️ للاستخدام الشخصي على أجهزتك بس، وما يتوزعش (رخص الخطوط).

## التحديثات
أحدث نسخة دايمًا هنا: **https://github.com/Mohamed-Elsawaf/reel-cutter/releases/latest**

البانل بيتأكد لوحده كل ما يتفتح. لو فيه نسخة أحدث هيظهر شريط فوق، تدوس **حمّل التحديث**، وبعدين دبل كليك على الـ `.ccx` اللي نزل. الإعدادات بتفضل زي ما هي.

**نشر نسخة جديدة (للمطوّر):**
1. علّي رقم النسخة في `plugin/manifest.json`.
2. شغّل `python tools/package.py --url-base https://github.com/Mohamed-Elsawaf/reel-cutter/releases/download --notes "إيه الجديد"`.
3. `gh release create v<النسخة> dist/ReelCutter-<النسخة>/ReelCutter-<النسخة>.ccx dist/ReelCutter-<النسخة>.zip`
4. اعمل commit و push لـ `version.json`، ومن ساعتها كل الأجهزة هتشوف التحديث.

## للتطوير
- `plugin/`: كود البلاجن (UXP, JavaScript من غير build).
- `tests/`: `node --test tests/`.
- `tools/package.py`: بيعمل `dist/ReelCutter-<version>/`.
- `SPIKE_NOTES.md`: سلوك Premiere API اللي اتأكدنا منه جوه بريمير.
- `DESIGN.md`: مرجع شكل البانل.
